# Exemples de prompts — comment demander de l'aide au skill

> Un bon skill mal sollicité donne des résultats moyens. Voici des prompts prêts à copier, par situation.
> Règle générale : donnez **le public, l'objectif, la durée et le format** si vous les connaissez. Sinon, le skill posera 3 questions max ou produira une V0 avec des hypothèses.

---

## Cadrer une idée floue
```
J'ai une idée à présenter mais c'est encore flou : [décrire en 2-3 lignes].
Aide-moi à clarifier le public, l'objectif, le message essentiel et un angle.
```

## Préparer une présentation complète
```
Je dois présenter [sujet] à [public] dans [durée], format [oral+slides / note / visio].
Objectif : [informer / convaincre / déclencher]. Décision attendue : [...].
Prépare l'intervention complète : diagnostic, PDFR, message essentiel, scénario,
plan de slides avec titres conclusifs, script oral, conclusion et Q&A.
```

## Pitch projet / innovation (2 min)
```
Je dois pitcher mon projet [nom] à [décideur] en 2 minutes.
Construis-moi le pitch en 4×30 s (Problématique → Solution → Équipe → Besoin).
```

## Reco / arbitrage devant un décideur (décision-first)
```
Je dois faire valider [recommandation] par [CODIR / mon manager] en [durée].
Construis un pitch décision-first : décision demandée, pourquoi maintenant,
preuves chiffrées, risques & parades, prochaine étape.
```

## Analyser une présentation existante (macro + détail)
```
Voici ma présentation : [partager les slides / décrire].
Public : [qui]. Objectif : [informer / convaincre / déclencher]. Durée : [X min].
Lance le MODE ANALYSE : d'abord l'analyse macro, puis slide par slide (fond + forme),
puis la synthèse avec les 3 priorités de correction et la note.
```
> Pour l'analyse de la **forme** (police, contraste, design), joignez le **fichier ou des images** — sinon le skill se limitera au fond.

## Transformer un contenu brut en slides
```
Voici mon contenu brut : [coller].
Transforme-le en plan de slides : une idée par slide, archétype adapté,
titre conclusif et message oral pour chaque slide.
```

## Réécrire une formulation
```
Réécris ces éléments pour qu'ils soient plus clairs et plus impactants :
- titre : [...]
- objectif : [...]
- conclusion : [...]
```

## Préparer l'oral et les questions
```
J'interviens [quand] devant [public]. Prépare-moi : accroche, transitions,
conclusion forte, les objections probables et mes réponses, et une routine anti-trac.
```

## Présenter en visio
```
Je présente [sujet] en visio (Teams/Meet) à [public] pendant [durée].
Adapte le plan de slides et donne-moi les règles spécifiques au distanciel.
```
